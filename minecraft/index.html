Java Edition 26.3

play.northstarprime.net

Java port: 25565 (the default).

  1. In the Minecraft Launcher, choose Latest Release. It must be 26.3: if a newer release has appeared, choose Installations, then New installation, and pick release 26.3.
  2. Start the game, open Multiplayer, choose Add Server and enter play.northstarprime.net as the Server Address.
  3. Save the entry, select it and choose Join Server.

No client mods are needed. Accept the server resource pack when prompted to load all custom NorthStar models, audio, and world textures.

Bedrock on Windows, phone or tablet

Add NorthStar to your server list using the Bedrock address and port below, or launch directly into Minecraft Bedrock.

Address: mc.northstarprime.net
Port: 25130

  1. Open Minecraft, choose Play, then the Servers tab, then Add Server.
  2. For Server Address, enter mc.northstarprime.net.
  3. For Port, enter 25130, then save the server and join it.

Xbox · Friends route

On Xbox, join straight through the Friends tab using the cross-play account below.

Xbox friend account: UncleVorath

  1. Add the Xbox account UncleVorath as a friend (auto-accepted).

PlayStation & Nintendo Switch

Join on PS4, PS5, or Nintendo Switch via the Friends tab or a Bedrock LAN helper:

  1. Sign in with your Microsoft account for cross-play, add UncleVorath as a friend, and look under Play → Friends for the NorthStar world.
