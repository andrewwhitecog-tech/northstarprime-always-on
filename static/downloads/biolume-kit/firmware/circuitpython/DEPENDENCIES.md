# CircuitPython dependencies
#
# Required (usually bundled with Circuit Playground Boards / CircuitPython
# builds that include Adafruit Circuit Playground support):
#   - adafruit_circuitplayground  (from Adafruit CircuitPython Bundle)
#   - neopixel                     (from Adafruit CircuitPython Bundle)
#
# Board must be running CircuitPython (not Arduino firmware).
# Download UF2 for your board from:
#   https://circuitpython.org/board/circuitplayground_express/
#   https://circuitpython.org/board/circuitplayground_bluefruit/
#
# After CircuitPython is installed, CIRCUITPY appears as a USB drive.
# Copy code.py to the root of CIRCUITPY. Libraries go in CIRCUITPY/lib/.
#
# No third-party private libraries are required for this kit.
