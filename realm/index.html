Enter the living realm.

Join the NorthStar world from Minecraft Java Edition 1.21.1. No client mods or extra pack are needed.

The Java world is open to anyone with a licensed account, with room for 100 players at once. Land claims and a rollback log protect what you build. A plain Java 1.21.1 player joined, explored and chatted here on October 15, 2026.

Your server address

play.northstarprime.net

  1. In the Minecraft Launcher, choose Installations, then New installation, and pick release 1.21.1.
  2. Start the game, open Multiplayer, choose Add Server and enter the address above.

A licensed Minecraft Java Edition account is required.
