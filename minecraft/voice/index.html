NorthStar · Optional Java voice

Bring your voice along.

Proximity voice setup is not ready yet for Minecraft Java Edition 26.3, the version the server moved to on October 30, 2026. Voice is optional: you can still join and play without the mod. This Java client mod does not give Bedrock players voice chat.

Set up your Java client

Don't follow these steps yet. They build a 1.21.1 client, which can't connect to the server on 26.3. This page will change once voice is ready for 26.3.

  1. Use a Fabric profile for Minecraft Java 1.21.1 with Java 21.
  2. Download Simple Voice Chat 2.6.22 for Fabric 1.21.1. Put voicechat-fabric-1.21.1-2.6.22.jar in that profile’s mods folder. Choose the Fabric build, then launch that profile.
  3. Join NorthStar. Press V to open the onboarding guide. Select your microphone and headphones, test your input level and choose push-to-talk or voice activation.
  4. Choose a push-to-talk key during onboarding. You can change it under Options → Controls → Key Binds. The V menu also controls volume, muting, devices and groups.

Keep it welcoming

The staged proximity range is 48 blocks, with a 24-block whisper range. Keep conversations all-ages, ask before recording and respect mute choices. Voice remains optional.

If voice will not connect

Check the game and mod versions, selected microphone and operating-system microphone permission. A disconnected icon can also mean the server’s separate UDP voice port is not ready or your network blocks it. The server installation and two-client voice check are still pending.
