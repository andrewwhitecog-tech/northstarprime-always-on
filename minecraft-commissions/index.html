What we make

Custom landmark build

A build made to your idea or reference art: spires, gates, temples, arenas. You get four isometric renders (NE, NW, SE, SW) and a top view to approve before install.

Remodel an existing build

We rework buildings already in your world in place: roofs, towers, facades and greenery, while rails, redstone, containers and shelves stay where they are. You see before and after renders first.

Fit to your lot

We place the build on a copy of your world first: footprint gaps filled, no floating blocks, nothing you already built overwritten.

Install-ready files

Vanilla Java function files for 1.21.1 and 26.3. Every fill only replaces the exact block it expects, work is split into staged parts, and a datapack zip is included.

Custom mobs and bosses

Server-side datapack enemies and boss fights, like the 18 horrors and 4 bosses in our Ossuary Sanctum.

Working displays

Fountains and falls that actually run, like our 10 liquid displays proven on a Java 26.3 server: contained lava, steady tick rate and a one-command undo.

How it works

  1. Send your idea, references and lot size.
  2. We share a concept and block renders.
  3. You approve or ask for changes.
  4. You get install files and placement notes.

What we check before we call a machine working

  • A long test run on a real server
  • Item counts that add up at every checkpoint
  • Undo checked block by block
  • A no-jump walk through the build
  • Live reload with 0 errors
  • A second reviewer on the real renders
