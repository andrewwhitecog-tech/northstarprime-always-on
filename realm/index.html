NorthStar · Public Minecraft world

Enter the living realm.

Explore the NorthStar world with Minecraft Java Edition 1.21.1 or Bedrock Edition. Choose your device below for the address and joining steps.

Java 1.21.1 and Windows Bedrock are open. Xbox Friends joining is still being checked. Choose your device below.

Java Edition 1.21.1

play.northstarprime.net

Java port: 25565 (the default).

  1. In the Minecraft Launcher, choose Installations, then New installation, and pick release 1.21.1.
  2. Start the game, open Multiplayer, choose Add Server and enter play.northstarprime.net as the Server Address.
  3. Save the entry, select it and choose Join Server.

A licensed Minecraft Java Edition account is required. No client mods or extra pack are needed for this Java joining route.

Bedrock on Windows, phone or tablet

Add NorthStar to your server list using the address and port below.

Verified on Windows Bedrock. Phone and tablet joins have not yet been confirmed.

Address: play.northstarprime.net
Port: 25130

  1. Open Minecraft, choose Play, then the Servers tab, then Add Server.
  2. For Server Address, enter play.northstarprime.net.
  3. For Port, enter 25130, then save the server and join it.

Xbox · Friends route

On Xbox, join through the Friends tab using the steps below. Xbox Friends joining is still being checked.

  1. Add the Xbox account UncleVorath as a friend.
  2. Open Minecraft, choose Play, then the Friends tab.
  3. Look for UncleVorath under Joinable Friends. The exact world listing title may vary.

If UncleVorath is absent or the join fails, contact NorthStar with your device and the error shown. The broadcaster’s listing and your account’s multiplayer permissions may need checking. PlayStation and Switch joining have not been verified.

What you need

The NorthStar server is free to join. You need a licensed copy of Minecraft for your device and, on consoles, any applicable multiplayer subscription. Your account must allow multiplayer.
