Java Edition 26.3

play.northstarprime.net

Java port: 25565 (the default).

  1. In the Minecraft Launcher, choose Latest Release. It must be 26.3: if a newer release has appeared, choose Installations, then New installation, and pick release 26.3.
  2. Start the game, open Multiplayer, choose Add Server and enter play.northstarprime.net as the Server Address.
  3. Save the entry, select it and choose Join Server.

A licensed Minecraft Java Edition account is required. No client mods are needed. The server will ask you to accept its resource pack. You must accept it: if you decline, you'll be disconnected. A direct list check on 9 Nov 2026 reported Java version name 26.3, protocol 777, 0 of 100. It did not report 1.21.1. The same minute, Bedrock’s list ping on UDP 25130 reported version 26.60, protocol 2225, 0 of 100, name NorthStar Prime.

Bedrock on Windows, phone or tablet

Add NorthStar to your server list using the address and port below, or open it directly in Minecraft Bedrock.

Bedrock answers on this address and port. A direct join on this port has not been recorded since the server moved to 26.3 on October 30, 2026; the Xbox Friends route below worked on November 4. If a direct join fails, use that route, or tell us your device and the error shown. Phone and tablet joins use the same address and port.

Address: play.northstarprime.net
Port: 25130

  1. Open Minecraft, choose Play, then the Servers tab, then Add Server.
  2. For Server Address, enter play.northstarprime.net.
  3. For Port, enter 25130, then save the server and join it.

Xbox · Friends route

On Xbox, join through the Friends tab using the steps below. Last seen working on an Xbox console on November 2, 2026, after the move to 26.3. On November 4, 2026, a Bedrock player on Windows joined through this same Friends route.

Xbox friend account: UncleVorath

  1. Add the Xbox account UncleVorath as a friend; the broadcaster accepts automatically.
  2. Open Minecraft, choose Play, then the Friends tab.
  3. Look for UncleVorath under Joinable Friends and join the NorthStar world.

If UncleVorath is absent or the join fails, contact NorthStar with your device and the error shown. The broadcaster’s listing and your account’s multiplayer permissions may need checking. PlayStation and Switch joining have not been verified.

PS4, PS5 and Nintendo Switch · untested

NorthStar joins on these consoles have not been tested. Their Servers tab has no normal Add Server option; the Windows and phone steps above do not apply.

  1. In Minecraft Bedrock, sign in with the Microsoft account you use for cross-play. Add UncleVorath, then check Play → Friends (or Worlds → joinable friends) for the NorthStar world. Availability depends on the broadcaster and your multiplayer permissions.
  2. If no world appears, try a LAN helper listed in Geyser's console guide. Keep the helper device and console on the same Wi-Fi, enter play.northstarprime.net and port 25130, leave the helper running, then check for its LAN game. Console and helper support varies.
  3. Alternatively, follow the BedrockConnect project's console-specific instructions and enter that same address and port in its server menu. It is a separate third-party tool; follow its current setup rather than an old DNS address.

These are routes to try, not verified NorthStar console joins. If they fail, send your console model and exact error.
