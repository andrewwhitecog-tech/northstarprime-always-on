Eleven worlds, ready to explore

Live clocks, animated artwork, theme selection, a five-minute automatic cycle, and a little lore and interaction in every world.

A home on your desktop

The Windows app offers Full, Half, Float and Bar layouts, top or bottom placement, and a draggable clock. Full-screen controls stay within reach from the narrow bar.

Yours to open and change

The clock and bundled artwork work offline after download. NorthStar code uses the MIT license; artwork permissions and third-party notices are included.

Also inside: Station 108, Signal Library, Seraphim Oracle, Ring Sentinel, Iron Omen, Electric Garden, Witness Chamber and Astral Hall. Images show the bundled world artwork; open the clock to see the moving displays.

How do I use the browser clock?

Choose a world with the dots along the bottom. Press Space to pause or resume automatic switching, F for fullscreen where your browser permits it, L for Lore and I for Interact. Seraphim's sound starts muted; enable it in that world's Interact panel. Use your browser's Back button to return here.

Ordinary browser tabs do not have the Windows app's floating, pinned or bar layouts. The desktop download provides those controls.

How do I install the Windows app?

Extract the complete ZIP into a folder, keeping its contents together, and run ChronosphereShell.exe. Install the two Microsoft runtimes linked above if needed. The app does not install a background service or require a NorthStar account. The README includes build instructions and troubleshooting.

Use Full, Half, Float or Bar to change its size. F returns to Full; Escape leaves Bar for Float. Full mode shows the complete worlds when the window is tall enough; the shorter desktop layouts use dedicated clock artwork.

What is optional, and what stays on my device?

Chronosphere itself has no account or application analytics. The downloaded clock, art and sound run offline; theme and layout preferences are saved locally. The optional local health display is for people who choose to connect their own service in the downloaded edition. The public demo does not need that connection. Microsoft runtimes have their own update and diagnostic settings.

Can I adapt the app or use the art?

Yes. The repository includes the complete clock code, native Windows shell, theme artwork and build instructions. See the MIT license, artwork permissions and provenance, and included Microsoft component notices for their respective terms. NorthStar's name is not an endorsement of modified versions.

What should I know about this first release?

The Windows build is unsigned and has not been tested on a fresh Windows installation or every monitor setup. The artwork includes motion and flicker. Reduced-motion preferences limit CSS animation, but do not stop every canvas effect. A complete screen-reader audit has not been performed. The displayed fictional instruments are part of the artwork.
